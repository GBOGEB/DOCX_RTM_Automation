# Quick Start Guide: Lua for RTM Automation

## Introduction

This guide provides a quick start for using Lua scripts within the RTM Automation project. Follow the steps below to set up and execute your first Lua script.

## Prerequisites

- Lua installed on your system.
- Basic understanding of scripting and programming concepts.

## Setup

1.  **Install Lua**
    Download and install Lua from the [official website](https://www.lua.org/download.html).

2.  **Verify Installation**
    Open a terminal and run:

    ```bash
    lua -v
    ```

    This should display the installed Lua version.

## Writing Your First Script

1.  **Create a Script File**
    Create a new file named `script.lua` in your desired directory.

2.  **Add Sample Code**
    Open the file and add the following code:

    ```lua
    print("Hello, World!")
    ```

3.  **Run the Script**
    Execute the script using:

    ```bash
    lua script.lua
    ```

## Next Steps

- Explore Lua documentation to learn more about its syntax and features.
- Experiment with variables, loops, and functions to build more complex scripts.

This quick start guide should help you get started with Lua scripting in the RTM Automation project. For more detailed information, refer to the official Lua documentation and the project-specific Lua API documentation.
