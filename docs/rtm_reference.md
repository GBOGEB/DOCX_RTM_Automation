## Introduction
This document serves as a reference for the Requirements Traceability Matrix (RTM) used in the automation process.

## Requirements Traceability Matrix (RTM)
The RTM is a tool used to ensure that all requirements are accounted for and tested during the development lifecycle.

## Usage Guidelines
- Ensure all requirements are listed in the matrix.
- Maintain traceability between requirements and test cases.
- Update the matrix as changes occur.
